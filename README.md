# Bank-and-Loan-Analytics
End-to-end Banking &amp; Loan Analytics project using Excel, SQL, Tableau, and Power BI.

## Overview
This project delivers comprehensive insights into banking loan portfolio performance, delinquency rates, default risk, and branch revenue collection across 65K+ records.

## Tools Used
- **Excel:** Initial data cleaning and KPI prototyping
- **MySQL:** Relational schema design, normalization, and aggregation queries
- **Power BI & Tableau:** Interactive dashboards tracking 18+ financial KPIs

## Key Insights & Features
- Tracked Delinquency Rate, Default Rate, and Total Collections across states and branches.
- Built 15+ DAX measures and automated Power Query reporting.
- Performed end-to-end QA checks between database records and visual metrics.
